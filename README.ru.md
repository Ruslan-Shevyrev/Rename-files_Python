# Rename Files in Order

[Read in English](README.MD)

Графическая утилита для пакетного переименования файлов. Можно пронумеровать файлы в порядке кликов по миниатюрам или по имени.

## Скачать и запустить

Скачайте архив `RenameFilesInOrder-<версия>-windows-x64.zip` со страницы [Releases](https://github.com/Ruslan-Shevyrev/rename-files-in-order/releases), распакуйте его целиком и откройте `RenameFilesInOrder.exe`. Устанавливать Python для запуска готовой версии не нужно.

## Как пользоваться

1. Выберите папку через **«Обзор…»** или введите путь вручную. Слева появится список файлов с миниатюрами фотографий и видео.
2. Введите новое имя без расширения и задайте начальный номер. Например, имя `Фото` и начальный номер `10` дадут `10. Фото.jpg`, `11. Фото.jpg` и так далее. Расширения сохраняются.
3. Для своего порядка щёлкайте по файлам в нужной последовательности. Кружки показывают порядок выбора. Повторный щелчок снимает выбор и пересчитывает следующие номера.
4. Нажмите **«Переименовать»**.

Если ничего не выбрано, программа переименует все файлы открытой папки по имени. Если есть выбор, по умолчанию меняются только выбранные файлы. Включите **«Добавлять невыбранные файлы в конец»**, чтобы после них пронумеровать остальные по имени. Сортировка в левой панели меняет вид списка. Подпапки можно открывать двойным щелчком, а переименование действует только в открытой папке.

## Запуск из исходников

В PowerShell из корня проекта с Python 3.13:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe rename_files.py
```

Интерфейс использует Tkinter. Pillow создаёт миниатюры изображений, а FFmpeg из `imageio-ffmpeg` извлекает кадры из видео.

## Сборка для Windows x64

Для сборки нужен 64-битный Python. Скрипт установит зависимости в `.venv` и соберёт переносимую папку через PyInstaller.

```powershell
.\build.ps1
.\dist\RenameFilesInOrder\RenameFilesInOrder.exe
```

Чтобы дополнительно создать ZIP для распространения:

```powershell
.\build.ps1 -Zip -Version v{VERSION}
```

Архив появится в `dist\RenameFilesInOrder-v{VERSION}-windows-x64.zip`. При отправке нового тега вида `v{VERSION}` GitHub Actions запускает ту же сборку и прикрепляет ZIP к релизу.
